# hyprcursor-sync  
`hyprcursor-sync` is a **simple auto cursor updater** for **Hyprland (only)** 

## Ft.
- Auto-sync cursor changes

## Deps
- Hyprland  (Obviously)
- Hyprcursor  
- NWG-Look

##  Installation
```bash
git clone https://github.com/uvz0/hyprcursor-sync
cd hyprcursor-sync
chmod +x ./install.sh
```

## Usage
```bash
./install.sh
```
